FAQs

How does URL shortening work?

URL shortening works by taking a long URL and creating a shorter, condensed version that redirects to the original URL. When a user clicks on the shortened link, they are redirected to the intended destination.

Is it necessary to create an account to use the URL shortening service?

No. You can shorten links without an account, but signing up lets you manage links, use custom domains and view analytics.

Are the shortened links permanent? Will they expire?

Links stay active for as long as your account does. You can also set an expiry date on any link you create.

Are there any limitations on the number of URLs I can shorten?

The Basic plan includes unlimited URL shortening. Paid plans add more customization, analytics and team features.

Can I customize the shortened URLs to reflect my brand or content?

Yes. Use custom slugs, branded links and custom domains to keep every link on brand.

Can I track the performance of my shortened URLs?

Yes. Every link comes with analytics showing clicks and scans, with richer reporting on paid plans.

How secure is the URL shortening service? Are the shortened links protected against spam or malicious activity?

Links are scanned for spam and malicious destinations, and suspicious links are blocked or flagged.

What is a QR code and what can it do?

A QR code is a scannable image that opens a link. Use it on print, packaging or events to bring people straight to your page.

Is there an API available for integrating the URL shortening service into my own applications or websites?

Yes. API access is included with the Teams plan so you can create and manage links from your own apps.
